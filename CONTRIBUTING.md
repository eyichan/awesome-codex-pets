# Contributing

Thanks for improving Awesome Codex Pets.

This repository is a curated directory of downloadable Codex Pets. Entries should link back to working pages on [codexpets.org](https://codexpets.org).

## Entry Requirements

Each pet entry should have:

- a stable pet page: `https://codexpets.org/pets/{pet-id}`
- a direct download endpoint: `https://codexpets.org/api/pets/{pet-id}/download`
- a manifest URL: `https://codexpets.org/pets/{pet-id}/pet.json`
- a spritesheet URL: `https://codexpets.org/pets/{pet-id}/spritesheet.webp`
- a short description

## Update Flow

1. Update the source catalog on codexpets.org.
2. Regenerate this repository from the site catalog.
3. Confirm links resolve before opening a pull request.

## Notes

Codex Pets is an independent community utility. It is not an official OpenAI product.
